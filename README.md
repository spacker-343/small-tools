# 小工具们

个人实用工具合集，每个文件夹都是一个独立工具。使用前请先阅读对应文件夹里的说明。

| 工具 | 作用 |
| --- | --- |
| [AutoMinimizePopup](AutoMinimizePopup/) | 自动收起符合规则的临时控制台窗口。 |
| [codex-vdesk-follow](codex-vdesk-follow/) | 将应用固定到 Windows 的所有虚拟桌面。 |
| [codex-obsidian-open](codex-obsidian-open/) | 在 Codex 中通过文件链接打开 Obsidian 笔记。 |

本仓库不包含编译后的可执行文件。AutoMinimizePopup 可以通过安装脚本在本机编译，详见该工具的说明。
